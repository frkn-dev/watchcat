# Гистерезис выдержки (switch_hold_ticks)
#
# Проблема: при margin 20 % и EWMA с весом 30 % на пробах раз в 5 с роутер
# перекладывает трафик между выходами с разницей в единицы мс. Замер на
# msk-tw: 284 переключения за 7.8 суток, из них 220 — `better_candidate`,
# то есть «нашёл чуть быстрее». Реальный failover (`active_failed`) в этом
# шуме не виден.
#
# Решение: кандидат обязан быть лучше активного `switch_hold_ticks` тиков
# подряд, прежде чем его поставят. Смена лидера или потеря преимущества
# обнуляют счётчик. Деградация активного (EWMA выше degrade_ms или в
# degrade_factor_pct раз выше медианы) выдержку не ждёт — там дорога каждая
# секунда.
#
# При пробе раз в 5 с выдержка 6 тиков = 30 с устойчивого преимущества.
# `switch_hold_ticks: 1` возвращает прежнее поведение (переключение по
# первому замеру) — это откат, если выдержка окажется слишком долгой.
#
# ## Бюджет неаварийных смен (degrade_switch_cooldown_ms, дефолт 1 час)
#
# Выдержка гасит дрожание «нашёл на пару мс быстрее», но не мешает менять
# выход несколько раз в час по деградации. Поэтому смена по причинам
# `active_degraded` и `better_candidate` разрешена не чаще одного раза за
# `degrade_switch_cooldown_ms` (по умолчанию 3 600 000 мс).
#
# Что бюджет НЕ трогает: потерю доступа. `active_failed` (выход в карантине),
# `active_blocked` (гео-блок без альтернатив), `active_missing` / `no_active`
# (члена пула больше нет) переключаются немедленно — «нет доступа» дороже
# лишней смены выхода.
#
# Бюджет считается от последней смены любого типа. Пока он не истёк, машина
# остаётся на текущем выходе, даже если активный просел по EWMA, и пишет
# `switch_deferred` (один раз на эпизод, не каждый тик) — чтобы тишина в
# аудите не читалась как «watchdog умер».
#
# `degrade_switch_cooldown_ms: 0` возвращает прежнее поведение (смена по
# деградации ограничена только `min_switch_interval_ms`).
#
# Рекомендуемая связка на боевой ноде:
#   switch_hold_ticks: 6              # 30 с преимущества
#   switch_margin_pct: 30             # порог по скорости
#   degrade_switch_cooldown_ms: 3600000   # неаварийные смены — не чаще раза в час
