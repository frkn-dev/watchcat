# Гистерезис выдержки (switch_hold_ticks)
#
# Проблема: при margin 20 % и EWMA с весом 30 % на пробах раз в 5 с роутер
# перекладывает трафик между выходами с разницей в единицы мс. Замер на
# msk-tw: 284 переключения за 7.8 суток, из них 220 — `better_candidate`,
# то есть «нашёл чуть быстрее». Реальный failover (`active_failed`) в этом
# шуме не виден.
#
# Решение: кандидат обязан быть лучше активного `switch_hold_ticks` тиков
# подряд, прежде чем его поставят. Смена лидера или потеря преимущества
# обнуляют счётчик. Деградация активного (EWMA выше degrade_ms или в
# degrade_factor_pct раз выше медианы) выдержку не ждёт — там дорога каждая
# секунда.
#
# При пробе раз в 5 с выдержка 6 тиков = 30 с устойчивого преимущества.
# `switch_hold_ticks: 1` возвращает прежнее поведение (переключение по
# первому замеру) — это откат, если выдержка окажется слишком долгой.
#
# Рекомендуемая связка на боевой ноде:
#   switch_hold_ticks: 6        # 30 с преимущества
#   switch_margin_pct: 30       # порог по скорости
#   min_switch_interval_ms: 600000   # не чаще раза в 10 минут
